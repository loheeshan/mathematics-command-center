# Mathematics field notebook

The rebuild adapts the user's AI Note visual design brief (sections 1–3 received on 20 November 2026) to mathematics. The product remains Mathematics Command Center. It does not change into an AI course.

## Learning contract

- Open directly into a beginner lesson; show one teaching object and one next action.
- Teach counting and arithmetic before algebra, then branch into geometry, computing, statistics, linear algebra and calculus.
- Offer student, developer, software engineer, data engineer and AI/ML paths. A path is a recommendation, never an access restriction.
- Separate visited, explored and checked states. Navigation alone never passes a checkpoint.
- Let learners save a note with its lesson, step and exact visual parameters, and restore that state.
- Keep the original detailed lessons, practice engine, labs and university resources accessible as the reference library.
- Retain browser-local data and export/import. Do not claim accounts, sync or an AI tutor.

## Interface

Warm ivory shell, dark ink outlines, sage actions, teal focus, lavender definitions and amber experiments. A left course tree, central visual workbench, adjacent explanation and bottom step navigation replace the dense entry dashboard. Use responsive stacked panels on phones, readable sans-serif prose and compact monospace labels. Quantity charts remain flat, with visible axes and text alternatives.

1. Authored guided curriculum and role paths, with validated dependencies and answers.
